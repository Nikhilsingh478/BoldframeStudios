==================================================
CREATIVE OBJECTIVE
==================================================

The existing site becomes conventional after the hero. We are replacing that portion with an authored, award-caliber creative studio experience.

BoldFrame should feel:
PREMIUM / EDITORIAL / EXPERIMENTAL / PRECISE / DIGITAL / CONFIDENT / TECHNICALLY SOPHISTICATED

But NEVER chaotic.

It must NOT feel like:
- Wix/Framer template
- AI-generated landing page
- SaaS dashboard
- Web3/cyberpunk site
- component-library demo
- random animation playground

Every animation needs meaning.

Core identity concept:

BOLD / FRAME

"Frame" can mean viewport, browser window, crop, composition, interface, project preview, film frame, boundary or moment.

Express this through composition and behavior:
- typography can intentionally crop at boundaries
- content can enter/escape frames
- imagery can transform from contained to viewport-scale
- borders can become interaction surfaces
- scroll can reveal different frames/moments

Do NOT literally cover the website in rectangles.

==================================================
POST-HERO VISUAL SYSTEM
==================================================

Preserve the hero's dark + violet + cyan DNA but mature it.

Post-hero:
near-black graphite around #08090B / #0A0B0E / #0C0D10.
Never use flat black everywhere.

Primary text: warm near-white around #F3F2EE.
Secondary text: muted #96989F range.
Primary accent: electric violet around #7357FF.
Secondary accent: cyan around #55DDF5, used VERY sparingly.

Inspect current colors and derive final tokens from them.

Do NOT:
- make everything purple
- use giant blurry gradient blobs everywhere
- overuse glassmorphism
- glow every container

Most visual richness should come from typography, spacing, composition, borders, imagery, negative space and motion.

==================================================
TYPOGRAPHY / COMPOSITION
==================================================

Inspect existing fonts first. Preserve a good existing font if appropriate. If another display font is necessary, use only a high-quality free/open-source face.

Maximum roughly two font families.

Need:
DISPLAY — architectural/editorial headlines
BODY — highly readable modern sans
MICRO — uppercase metadata

Use clamp() for large type. Desktop display moments can reach ~8-12vw where appropriate.

The OLD site is too centered. Fix that.

Use intentional asymmetry:
left alignment, offset typography, right metadata, edge relationships, occasional centered spectacle.

Do not make layouts randomly messy.

==================================================
MOTION RULE
==================================================

Motion must perform one of five jobs:

1. REVEAL — hierarchy
2. PROGRESS — journey position
3. TRANSFORMATION — state change
4. NAVIGATION — movement through content
5. FEEDBACK — interaction response

Avoid fade-up on every element.

Use transform/opacity where possible. Avoid layout-thrashing animation.

We will later use GSAP ScrollTrigger, Framer Motion, Lenis and Swiper. Do not install duplicate smooth-scroll systems.

If Lenis already exists, reuse it. If not, only introduce ONE subtle global smooth-scroll solution if safe. Scrolling must never feel delayed or fight the user.

All timelines, ScrollTriggers, RAF loops, observers and listeners must clean up correctly.

Never kill every ScrollTrigger globally from one component.

Support prefers-reduced-motion.
