01 — PURPOSE OF THIS SECTION
==================================================

Create an original BoldFrame scroll journey inspired by the supplied scroll-following SVG path concept.

DO NOT copy the reference SVG path.

DO NOT copy its green color.

DO NOT copy its composition or wording.

The reference is only inspiration for the interaction principle:

USER SCROLL PROGRESS → SVG LINE DRAWS FORWARD.

For BoldFrame, this line must have meaning.

It represents the studio journey:

IDEA
→ FRAME
→ DESIGN
→ BUILD
→ REFINE
→ final experience

The user should feel as though scrolling physically constructs the creative process.

This should become a signature visual moment of the website.

It must NOT look like a decorative squiggle placed behind text.

==================================================

Place this directly after the completed Capabilities experience.

Do not center everything.

03 — ORIGINAL SVG PATH
==================================================

Create a NEW custom responsive SVG path specifically for this layout.

The path should begin close to the opening typography and travel through the entire section.

Its visual personality:

CONFIDENT
FLUID
CONTROLLED
SLIGHTLY HUMAN
PRECISE ENOUGH TO FEEL DESIGNED

NOT:
- childish doodle
- random spaghetti
- corporate flowchart
- perfect symmetrical wave
- giant looping scribble copied from Skiper19

The path should move naturally around typography and checkpoints.

Use a large SVG viewBox so curves remain smooth.

Use cubic Bezier curves intentionally.

Desktop stroke width approximately 6-10px depending on viewport.

Mobile approximately 3-5px.

Use round linecap and linejoin.

Primary color should be BoldFrame violet.

A VERY subtle violet→cyan evolution may be used toward the end if elegant and consistent with the hero DNA.

Do not create rainbow gradients.

If gradient reduces visual clarity, use solid violet.

04 — SCROLL-DRAW BEHAVIOR
==================================================

Connect path drawing directly to this section's scroll progress.

Use either:
- Framer Motion useScroll/useTransform
OR
- GSAP ScrollTrigger

Choose whichever is most robust with the architecture already established.

Do not add another animation library solely for this.

CRITICAL:

The path must begin essentially undrawn.

At section progress 0:
pathLength ≈ 0

At roughly 90%:
pathLength ≈ 1

Final ~10% provides visual breathing room.

Unlike the original reference, DO NOT start around pathLength 0.5.

The visitor must visibly CREATE the route.

The path drawing should map almost linearly to scroll.

Do not apply dramatic easing to scroll-linked progress.

Scrolling backward must naturally erase/reverse the journey.

No animation should continue independently after the user stops scrolling.

==================================================
05 — PATH / TYPOGRAPHY LAYERING
==================================================

Make the line interact spatially with the composition.

Some segments should:

- pass BEHIND huge typography
- emerge back into foreground
- travel through negative space
- curve around metadata
- pass behind a small "frame" object
- arrive at checkpoints

Use z-index, masks and/or SVG clipping deliberately.

Example:

The path approaches "ROUGH IDEA", disappears behind several letters, then emerges from the opposite edge.

Later it may wrap around an outlined browser/frame shape before continuing.

This creates depth WITHOUT generic floating 3D objects.

Do not compromise text readability.

07 — CHECKPOINT ACTIVATION
==================================================

Checkpoint animation must be tied to PATH PROGRESS.

The line should visually reach a checkpoint BEFORE or AS that checkpoint activates.

Do not have all labels independently fade in just because they entered viewport.

Activation sequence:

1. path approaches point
2. small anchor point activates
3. label changes muted → near-white
4. title resolves into full contrast
5. supporting sentence reveals subtly

Possible motion:

opacity 0.3 → 1
translateY 10-16px → 0
scale 0.97 → 1

Keep it restrained.

No bouncing.
No particle explosions.
No giant glows.

The active anchor can have a tiny violet pulse ONCE.

Inactive checkpoints remain readable but subdued.
