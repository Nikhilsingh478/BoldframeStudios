==================================================
06 — GSAP / SCROLLTRIGGER
=========================

Use GSAP ScrollTrigger.

Pin the manifesto viewport while its track moves horizontally.

Calculate horizontal travel from REAL dimensions.

Conceptually:

horizontalDistance =
track.scrollWidth - viewportWidth

Do NOT hardcode arbitrary translateX values such as -500vw.

Use function-based GSAP values where appropriate so ScrollTrigger can recalculate after resize.

The movement must begin only when the section reaches the correct position.

Suggested behavior:

start: "top top"
pin: true
scrub: approximately 0.7-1.0
invalidateOnRefresh: true

Determine end distance from actual horizontal travel.

Do not make the scroll excessively long.

The user should feel momentum, not imprisonment.

==================================================
07 — ROBUST INITIALIZATION
==========================

This is React.

Widths MUST be accurate before ScrollTrigger calculates pinning.

Use useLayoutEffect/useGSAP appropriately.

Account for:

* font loading
* DOM rendering
* responsive width changes
* inline visual dimensions

Where necessary use:
document.fonts.ready

followed by:
requestAnimationFrame / ScrollTrigger.refresh()

A tiny controlled initialization delay is acceptable if technically necessary.

Do NOT use arbitrary multi-second timeouts.

Use ResizeObserver only if useful.

Clean it up.

Scrolling backward must work perfectly.

==================================================
08 — PINNING QUALITY
====================

This section must feel exceptionally stable.

No:

* jump when pin activates
* blank vertical gap
* track clipping incorrectly
* horizontal body scrollbar
* sudden speed changes
* stuck pin
* content disappearing after resize
* conflict with Lenis

If Lenis exists, ensure ScrollTrigger synchronization is correct.

Do not introduce a second smooth-scroll engine.
